# ADR-002: 依赖版本约束策略

**状态**: 已接受
**日期**: 2026-04-14
**决策者**: OpenClaw Agent

---

## 背景

Python 依赖在 requirements.txt 中使用宽松版本约束（如 `>=`），可能导致不同环境安装不兼容的版本。

## 决策

采用**宽松但有限制**的版本约束策略：

1. **核心依赖**: 添加小版本上限
   ```
   fastapi>=0.104.1,<0.105.0
   sqlalchemy>=2.0.23,<2.1.0
   ```

2. **AI 相关依赖**: 添加次版本上限（因为更新频繁）
   ```
   langchain>=0.3.0,<0.4.0
   langchain-core>=0.3.0,<0.4.0
   ```

3. **安全相关依赖**: 添加大版本上限
   ```
   cryptography>=41.0.0,<42.0.0
   bcrypt>=4.0.0,<5.0.0
   ```

## 后果

**正面**:
- 防止破坏性更新
- 提高环境一致性
- 减少依赖冲突

**负面**:
- 需要定期更新上限版本
- 可能错过一些安全补丁（但可通过 Dependabot 缓解）
