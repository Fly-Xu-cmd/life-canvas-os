# ADR-001: 测试配置统一方案

**状态**: 已接受
**日期**: 2026-04-14
**决策者**: OpenClaw Agent

---

## 背景

项目的测试配置分散在多个文件中，pytest、Playwright 等工具缺少统一的配置和覆盖率报告。

## 决策

1. **pytest 配置**: 在 `backend/pytest.ini` 中统一配置
   - 异步测试模式
   - 覆盖率报告 (XML + Terminal)
   - 警告过滤

2. **CI 集成**: 在 `build.yml` 中添加覆盖率报告上传
   - XML 报告用于 CI 系统集成
   - Terminal 报告用于日志

## 后果

**正面**:
- 测试配置集中管理
- 统一的覆盖率报告

**负面**:
- 需要维护额外的配置文件
